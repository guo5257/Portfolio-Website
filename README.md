# TIAN 个人作品集

React 19 + Tailwind CSS 4 + Vite 构建的纯静态响应式作品集，面向招聘方与潜在客户。页面分为七个内容板块：封面、个人档案、品牌经历、环绕拼贴、重点项目、服务与评价、联系信息。

## 本地运行

    npm install
    npm run dev

构建命令：npm run build。网站没有后台或内容管理系统。

## 替换内容

- 首屏主视觉：public/images/portfolio-cover.jpg。Hero 组件中的 data-media-slot="hero" 容器可在下一阶段换成视频、Canvas 或 3D 内容。
- 项目、品牌、服务、评价和联系方式：统一编辑 src/data.js。
- 项目图片：存放于 public/images/，当前四张作品图已接入拼贴与重点项目。
- 个人档案左侧物件图、结尾右侧灰度图：目前复用封面图；收到新的肖像或物件图后可分别替换。
- 客户评价、所在地、电话、微博、微信及邮箱仍是明确的占位内容。发布前应填写真实资料，并确认评价获得使用授权。

## 交互说明

桌面导航使用页内锚点，移动端为展开式菜单。品牌名称从左向右循环移动，鼠标悬停时暂停。重点项目使用 CSS sticky 随原生滚动逐层堆叠，反向滚动会展开。系统启用“减少动态效果”时，循环动画关闭，项目卡改为普通顺序排列。作品图片可点击放大并缩放预览。
